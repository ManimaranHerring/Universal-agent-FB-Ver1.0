# Universal Agent Starter — Full Demo


Two agents + synthetic datasets for a live demo:
- **RFQ → Quote Agent** — parses an RFQ CSV, applies pricing logic, returns a priced quote with totals and a CSV export.
- **AP 3‑Way Match Agent** — matches PO ↔ GRN ↔ Invoice, flags exceptions, and exports a CSV.


No API keys. Node.js 18+ recommended (works on Node 20+ as well).
